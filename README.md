# JisooEngine

DirectX 12와 C++20으로 개발하는 Windows용 3D 게임 엔진입니다.  
엔진 구조와 렌더링 시스템을 직접 설계하고 구현하며, 각 계층의 책임과 생명주기를 명확하게 나누는 것을 목표로 합니다.
